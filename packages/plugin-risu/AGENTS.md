# 插件开发约定

角色卡、服装、模型、生图参数、画师、Prompt、自动配图设置和图片历史均在独立服务管理台配置和查看。插件只负责服务连接、配图、挂图和状态面板人设图，并提供管理台链接；不要在插件内嵌管理编辑器、管理员令牌表单、本地设置页、图片历史或第二层配置导航。配图上限、画幅和输入长度由服务决定，插件不再保存本地设置。

Risu 画图插件源码位于魔女画匣工作区的 `packages/plugin-risu`。Risu 仓库的 `plugins/global-comfy-image/` 接收构建分发文件。

本地已安装插件的备份和更新使用 `skills/risu-plugin-update/SKILL.md`，默认不使用 computer use。仅构建和分发可直接执行；写入真实存档前先按该技能检查 Risu 页面，检查通过或用户已确认关闭后使用配套脚本。不要未检查就默认要求用户关页；用户已确认关闭时不重复询问。用户明确要求安装更新时允许脚本修改目标插件代码；不要以验证重构为由修改真实存档。

- 使用 TypeScript 真正的 ES 模块，开启 strict；禁止 any、ts-nocheck 和共享闭包式源码拼接。
- 使用 Vite library 构建，配置在 vite.config.ts；不要另写打包器。
- UI 页面、DOM 组件和 CSS 位于 ui/；业务代码不能导入 UI 或访问 DOM，UI 通过类型化服务调用操作。
- 修改后运行 pnpm check、pnpm lint、pnpm test:e2e。只维护 Playwright E2E，不添加单元测试或源码切片测试。
- pnpm deploy 在检查通过后复制 Vite 产物，不自动修改存档内已安装的插件。
- 保留插件身份和存储键（`automatic-jobs`、`automatic-context-<digest>`、`paintbox-connection`），已有文件必须能读；插件只自用，不为旧版本保留回退兼容或兼容字段，涉及迁移需单独设计。
- 不擅自添加硬编码的内容关键词黑名单，也不将内容限制混入 JSON、坐标或资料 ID 等技术校验；如实显示模型服务的返回结果。
- 不修改真实 save、模型配置、密钥或正在执行的任务来验证重构。
- 文档只描述当前行为：功能被移除时，同时删除它的文档、测试和示例，不留“历史记录”段落。

- 配图流程：助手回复结束后一次请求服务选景和编写提示词，按插图分别排队生图。重画只提交所选图片已保存的提示词，挂载时按原文版本校验；单张重画和整楼重配都是新图挂载成功后才替换旧图。

- 状态面板人设图只经 display 处理器给消息追加作用域样式：写进样式的只有人物的 id、别名、短名和服务返回的图片链接，图片由页面按链接自取。不写角色卡，不访问主页面 DOM，不新增插件权限；处理器在启动时最先注册，早于读取任务和创建界面。面板的姓名、年龄、所属文字和各槽位的布局显隐仍由卡自身维护。
