# 魔女画匣 · Risu 插件

2.5.6 精简服务模式：插件只保留服务连接、配图和生图回顾，以及打开独立服务管理台的链接。角色卡、服装、模型、生图参数、画师、Prompt 和自动配图设置统一在服务管理台维护；插件不再嵌入编辑器，不接收管理员令牌，也不读写管理员配置接口。内部插件 ID `global-comfy-image` 保持不变，已有连接、任务和图片继续读取。回复后准备概括，点击各条「生图」后才生成图片。

Risu 角色卡的人物资料自动从 `library.people` 迁移到 `library.anchors`，角色字段与四方 `CharacterAnchor` 一致：`id/name/aliases/appearance/negative/outfits/selectedOutfitId/portrait/updatedAt`，服装使用 `id/name/tags`。服务启动迁移前会在原目录备份 `risu.before-anchors-*.json`。角色卡之间仍隔离；卡片、场景、画师预设及自动配图偏好保留。旧格式写入请求仍可读取并转换。下文第一步及本地服装的说明适用于保留的 legacy 模式。

聊天插图预览居中，最大宽 640px、高 480px，同时受聊天栏宽度和动态视口 70% 高度限制；点击仍可全屏查看。

Risu 2.3 起默认连接魔女画匣独立服务。在「服务连接」填写 Risu 主机上的回环地址和 Risu 专用服务令牌，点击「测试并保存服务连接」。规划模型、生图模型、画师串和规划资料由独立服务的配置决定。Risu 发送可配图的正文，保存并展示插图位置和 summary；用户点击生图后才请求并挂载图片。图片原件进入服务历史，聊天内保留 Risu 附件，旧任务和旧图可继续查看。

Risu API 3.0 小说配图插件。本分支使用 NovelAI。正文完成后，插件调用一次 Risu 配图模型选择插图位置并编写标签，每张图独立生成和重画。

## 开发与验证

```bash
cd packages/plugin-risu
pnpm install
pnpm exec playwright install chromium
pnpm check
pnpm lint
pnpm test:e2e
pnpm deploy
```

- `pnpm build`：严格 TypeScript 检查 + Vite library IIFE 构建，输出 `dist/plugin.js` 和 source map。
- `pnpm lint`：ESLint 检查代码和模块边界。
- `pnpm test:e2e`：构建后用 Chromium 操作完整插件界面，不运行单元测试。
- `pnpm deploy`：Lint、构建和 E2E 通过后复制产物到与本仓库同级的 `risu/plugins/global-comfy-image/`，回读校验 SHA-256。
- `pnpm format` / `pnpm format:check`：统一格式。

部署到其他 Risu 目录可运行 `pnpm deploy ../path/to/risu`。已导入存档的插件需在 Risu 插件管理中重新导入生成的 `plugin.js`；部署不修改真实存档或正在运行的任务。插件标识 `global-comfy-image` 和已有历史存储键继续兼容；旧图和资料可以继续查看。

本地已安装插件也可使用随插件分发的 [risu-plugin-update skill](skills/risu-plugin-update/SKILL.md) 和 WSL2 下的 Node TypeScript 脚本，无须操作浏览器导入。默认只读预览；用户关闭本地页面后传 `--apply --page-closed`，自动备份、替换插件代码并校验其他数据未变。支持仅恢复插件代码的回滚。

## 模块职责

第一步使用人物/场景列表和字段编辑器，支持搜索、新增、复制、移除以及扩展字段 JSON。未保存的表单草稿会在同一次插件会话内保留；刷新页面会丢弃草稿。资料版本变化时阻止旧草稿覆盖新版本，可重新载入后编辑。

公用服装预设跨角色共用，保存在独立的 `shared-outfits` 文件。首次使用内置“黑色兔女郎 · 黑丝裤袜”，包含颈部领结及双手腕结。已有保存列表（包括空列表）优先，不自动回填或迁移。人物详情可以预览并追加预设到外观草稿，保存人物后第二步仍按原协议读取 `appearance`。预设复制后独立，不建立自动联动引用。

人物详情现在直接编辑 `outfits`（服装名称、ID、描述）及 `defaultOutfitId`；默认服装可选人物专属或公用库 ID。新增服装不改写 `appearance`，扩展 JSON 中原有服装也会显示在表单里。旧的“追加到外观”入口保留供兼容资料使用；使用独立服装时应从固定外观中移除旧穿着，避免叠加。

“抽取设置 → 服装测试设置”可独立保存负向提示词。人物和公用服装库的试穿预览沿用已保存的人物外观或自定义外观，以及当前服装草稿。可先预览提示词，再用 RisuAI 已配置的 NovelAI 生成白底、全身、前侧 45° 的试穿图。试穿记录和结果可在刷新后查看，图片可下载。试穿直接调用 NovelAI，图片留在试穿面板。

“资料抽取与增量结果”内可仅预览实际输入，不调用模型或写入文件。“调试”保留最近一次请求消息、原始响应（包括解析失败）、耗时及宿主可取得的 token 用量，支持导出和粘贴响应离线校验。调试记录仅保存在当前插件会话内；导出文件包含故事原文。没有新增 Agent 编辑界面。

| 目录          | 职责与边界                                                                      |
| ------------- | ------------------------------------------------------------------------------- |
| `src/step1/`  | 资料抽取、审阅草稿、增量合并、版本保存；有自己的状态与设置                      |
| `src/step2/`  | 一次配图规划请求、按 ID 引用外观、NovelAI 队列、图片与历史 |
| `src/ui/`     | DOM 组件、表单、独立页面与 CSS，只读取状态并调用服务操作                        |
| `src/host/`   | 类型化 Risu API 和当前聊天上下文适配                                            |
| `src/shared/` | 模型、网络、存储、模板和状态通知等公共能力                                      |
| `src/domain/` | 跨模块数据协议及只读接口                                                        |
| `src/app/`    | 初始化、依赖装配、入口注册、恢复和卸载                                          |
| `e2e/`        | 完整产物的浏览器流程测试和隔离宿主                                              |
| `examples/`   | 通用配置和工作流示例，不含实际用户配置                                          |

第二步只接收 `LibraryReader`，不能导入第一步或调用资料写入接口。业务模块不能引用 UI 或 DOM；ESLint 约束这些依赖方向。页面之间不共享业务闭包，也没有源码片段清单或手写构建器。

## E2E 范围

浏览器加载 Vite 生成的完整 `dist/plugin.js`，从 UI 验证抽取、审阅保存、配置、预览、历史和图片交互；从宿主边界触发助手输出、消息图片请求及卸载。隔离宿主模拟 Risu 的模型与 NovelAI 接口。

覆盖一楼多图、分栏请求、重复事件、无图或无效计划、附件定位元数据、单张重画，以及资料库与移动布局。截图、失败 trace 和报告位于忽略的 `test-results/`、`playwright-report/`。

功能协议保留在 `docs/`；本工程的当前构建与测试方式以本文为准。

## NovelAI 楼层配图

在 Risu 图像生成设置配置 NovelAI V4 或更新的支持模型。在第二步选择负责选景的 Risu 模型席位，默认使用辅助模型。每楼默认最多 3 张，可修改上限、选景要求和全局画师词。AI 动态画幅默认开启，每张图可独立选尺寸，缺失或无效值沿用 Risu 的 NovelAI 宽高。关闭动态画幅后，新任务固定使用 Risu 的尺寸。

插件给正文副本的合适行尾编上 `P001` 等位置。单次请求应返回 JSON 数组，每项的 `at` 指向位置，`summary` 作为概括，`prompt` 为 `全局标签 | 人物一 | 人物二`。人物栏可用 `~` 添专属负面词，可用 `@人物ID` 引用固定外观、`@人物ID:服装ID` 引用专属服装，或 `@人物ID:#服装ID` 引用通用服装。没有选景时可返回空数组。配图请求同时发送当前角色、聊天及模块世界书中启用的常驻条目和本楼可见正文命中的关键词条目。世界书供配图模型提取标签，图片请求仍使用生成后的标签。

图片挂载到原回复，仅当原文版本匹配才保存附件。宿主在能唯一定位的段落后显示图片，翻译或排版处理使原句无法定位时在楼层末尾显示。重画沿用该图已保存的请求，并在新图挂载成功后替换旧图。

使用本分支需要同时构建包含角色分栏和附件位置支持的 Risu 宿主。历史协议参考 [旧主模型绘图](docs/MAIN-MODEL-GENERATION.md)。
