# 魔女画匣 · Risu 插件

Risu API 3.0 插件，内部 ID `global-comfy-image`。插件只负责三件事：连接魔女画匣独立服务、为助手回复配图并把图片挂回原文、把画匣人设图显示到 Risu 状态面板的肖像位。角色卡、服装、模型、生图参数、画师、Prompt、自动配图设置和图片历史都在服务管理台维护（默认 `http://127.0.0.1:4783`）；插件没有本地设置，不接收管理员令牌，也不读写管理员配置接口。

## 功能

**服务连接。** 在「服务连接」填写 Risu 主机上的回环地址和 Risu 专用服务令牌，点击「测试并保存服务连接」；插件校验服务的协议版本和配置版本，只接受本机回环地址。连接保存在 Risu 的插件文件里，令牌留空时沿用已保存的值。

**自动配图。** 助手回复完成后，插件把正文交给服务规划插图位置和概括，再逐张请求服务生图，依次挂回原回复。是否开启由服务管理台的自动配图开关决定，每次回复前都会向服务确认。同一回复的重复事件或重复点击不会建立第二个任务；任务持久化在 Risu 的插件文件里，刷新后继续，结果未保存的请求不会自动重发，避免重复生图。

**手动操作。** 「配图」页可以预览最新一轮的配图计划（只调用规划，不生图），也可以给最新已完成回复补图（复用已有结果，去重）。消息图片上的操作由 Risu 交给插件：单张重画沿用该图已保存的提示词，新图挂载成功后才替换旧图；整楼重配重新规划，新的一批全部挂载成功后才替换旧图；补图复用同楼已成功的结果。

**状态面板人设图。** 插件的 display 处理器在卡片正则之前运行，读取消息里的 `varId`，在本卡人物中匹配后给人设图位追加作用域样式。角色卡本身不改，也不新增插件权限；由服务管理台的「状态面板肖像取用画匣人设图」开关控制。协议见[状态面板人设图](docs/STATUS-PORTRAITS.md)。

**图片历史**不在插件里查看，统一在服务管理台。聊天里已经挂上的插图是 Risu 资源，属于聊天内容，不受插件任务记录影响。

## 开发与验证

```bash
cd packages/plugin-risu
pnpm install
pnpm exec playwright install chromium
pnpm check
pnpm lint
pnpm test:e2e
pnpm deploy
```

- `pnpm build`：严格 TypeScript 检查 + Vite library IIFE 构建，输出 `dist/plugin.js` 和 source map。
- `pnpm lint`：ESLint 检查代码和模块边界。
- `pnpm test:e2e`：构建后用 Chromium 加载完整产物，通过隔离宿主验证；不运行单元测试。
- `pnpm deploy`：Lint、构建和 E2E 通过后把产物、`docs/` 和 `skills/` 镜像到与本仓库同级的 `risu/plugins/global-comfy-image/`，回读校验 SHA-256。`docs/` 是镜像，源码里删掉的文档也会从分发目录消失。
- `pnpm format` / `pnpm format:check`：统一格式。

部署到其他 Risu 目录可运行 `pnpm deploy ../path/to/risu`。已导入存档的插件需在 Risu 插件管理中重新导入生成的 `plugin.js`；部署不修改真实存档或正在运行的任务。插件标识 `global-comfy-image`、任务文件和连接文件继续兼容，旧任务和待点击计划照常读取。

本地已安装插件可使用随插件分发的 [risu-plugin-update skill](skills/risu-plugin-update/SKILL.md) 和 WSL2 下的 Node TypeScript 脚本，无须操作浏览器导入。默认只读预览；用户关闭本地页面后传 `--apply --page-closed`，自动备份、替换插件代码并校验其他数据未变。支持仅恢复插件代码的回滚。

## 模块职责

| 目录          | 职责与边界                                                     |
| ------------- | -------------------------------------------------------------- |
| `src/step2/`  | 服务客户端、配图规划、生图队列、挂图、任务存储、状态面板人设图 |
| `src/ui/`     | 服务连接页、配图页和样式，只读取状态并调用服务操作             |
| `src/host/`   | 类型化 Risu API 和当前聊天上下文适配                           |
| `src/shared/` | 存储、摘要、状态通知等公共能力                                 |
| `src/domain/` | 数据协议                                                       |
| `src/app/`    | 初始化、依赖装配、入口注册、恢复和卸载                         |
| `e2e/`        | 完整产物的浏览器流程测试和隔离宿主                             |

业务模块不能引用 UI 或 DOM；ESLint 约束这个依赖方向。页面之间不共享业务闭包。

## E2E 范围

浏览器加载 Vite 生成的完整 `dist/plugin.js`，从界面验证服务连接、配图页和移动布局；从宿主边界触发助手输出、消息图片请求及卸载。隔离宿主模拟 Risu 的存储、附件和消息图片接口，服务接口由各用例按数据包协议模拟。

覆盖自动配图与去重、单张重画、整楼重配、补图复用、任务文件的升级与恢复、写入失败时的保留，以及状态面板人设图。截图、失败 trace 和报告位于忽略的 `test-results/`、`playwright-report/`。

功能协议保留在 `docs/`；本工程的当前构建与测试方式以本文为准。
