# 自动任务存储升级（2.5.2）

插件身份和 Risu 存储命名空间继续使用 `global-comfy-image`，显示名为魔女画匣。

旧 `automatic-jobs` 是完整任务数组。V2 是 `{ version: 2, jobs: [...] }`；每个任务的 `settings`、`pair` 移入 `automatic-context-<digest>`，任务使用 `contextRef` 引用。其余任务字段原样保留。资料库继续使用原有 `automatic-libraries` 协议。上下文按完整内容去重，不按可能重复的消息 ID 合并，不修改正文、设置或待点击计划。

读取同时兼容旧数组和 V2。旧数组不因读取而改写，在下一次正常保存时生成上下文并提交 V2 索引。上下文写入并通过原存储层读回验证后，才写索引；中途失败保留旧索引，多出的未引用上下文可供重试复用。索引写入确认失败时不发出绘图请求；保存操作只重试一次，不自动重发绘图请求。多个并发状态更新合并保存，所有等待者在最新状态保存成功后才继续。

启动恢复时保存失败只显示状态并暂缓恢复，不注销 UI 和消息处理器。不将存储故障冒充为模型错误。用户保持当前页面时内存任务仍保留，连接恢复后可再次操作，或重新打开页面恢复已持久化的任务。完全无法读取任务或上下文缺失时明确报错，不用空队列覆盖原数据。

已提交但未确认的绘图仍使用原有防重复恢复规则。已有终结任务保留策略不变，等待点击的计划不纳入终结历史清理。快照文件不主动删除，避免与仍引用该快照的索引竞争。

2.5.1 及更早版本不能读取 V2 索引；不能只回退插件脚本后沿用 V2 文件。需要回退时，先用 V2 读取并展开完整任务数组，再以旧协议写回任务；不得以清空队列作为回退方案。插件安装脚本不改写任务文件，迁移由新版插件通过 Risu 文件 API 执行。

Playwright 覆盖旧数组升级、共享快照复用、持续/短暂断连、保留待点击计划、刷新不重复出图。测试夹具的 `snapshot()` 返回展开后的逻辑任务以沿用业务断言，`rawSnapshot()` 用于验证实际索引与快照文件。
