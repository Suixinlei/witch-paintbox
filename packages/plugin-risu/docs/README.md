# 功能说明

插件由两个独立步骤组成：第一步手动抽取、审阅并保存角色的人物与背景资料；第二步用已保存资料和最新一轮对话构图并提交 ComfyUI。UI 提供独立的资料、抽取设置、生图设置和历史页面。
