# 回复图片

规划完成后，图片位先以概括挂到对应助手回复，生图完成再换成原图。原图由服务保存，插件通过 Risu 资源 API 存一份 `assets/…` 并附加到回复；关联使用稳定角色/聊天/消息标识及预期原文检查。原回复已修改或删除时挂载失败，但生成结果仍保留在服务的图片历史里。

挂载失败的任务在下次启动时自动重试，也可以在「配图」页点「为最新已完成回复自动配图」重新挂载，不重新调用规划或生图。需要原图时从服务管理台的图片历史下载。

聊天里的插图预览居中，最大宽 640px、高 480px，同时受聊天栏宽度和动态视口 70% 高度限制；点击可全屏查看。

图片持久化到当前服务器。生产插件没有浏览器存储回退；E2E 宿主使用隔离浏览器数据模拟服务器，不连接真实存档。
