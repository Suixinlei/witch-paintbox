# 结构与引用校验

校验 JSON 字段、人物 ID 与姓名对应、重复人物、背景引用及必需文本。没有内容关键词黑名单，身体部位词不作为拦截依据。

appearance 只引用第一步已保存资料，不接受模型重写。当前动作、姿态和本轮明确状态由单次模型输出的 action 描述。

资料姓名含括号内英文名或角色注释时，允许精确的括号前简称；按返回 ID 引用并还原完整资料姓名，不进行模糊匹配。其他姓名冲突仍报错。POV 统一使用当前用户姓名作为 observerName，相应资料索引姓名也统一为该称呼；内部 ID 只用于资料引用。

协议 v3 必须包含 view.mode、observerName、reason 和 visibleBodyParts。第一人称禁止把观察者列作第二个完整人物；自然可见的手、手臂或躯干边缘可以入画，不增加人数、不触发全身外观引用。接触或体位复杂、第一人称无法同时交代双方身体时可以选择 third_person 并说明叙事原因；第一人称接触场景必须填写观察者自然可见的接触局部。人物数统计 characters 中的唯一人物，允许局部裁切，不统计故事在场但画外的人物。结构校验不能保证生图模型严格执行人数或视角，实际效果仍需看图验收。

校验失败保留原响应并停止，不调用其他模型修正。JSON 模式约束语法，不能替代引用校验，也不能保证图像细节完全准确。

兼容模型将道具放入 scene.objects：可以仅有该数组，也可与顶层 objects 同时出现。本地合并时顶层同名道具优先，再补充嵌套数组中的其他道具，不重复拼接两套同名描述。原始响应保留，历史记录兼容提示，不追加模型请求。scene 的四个必需字段、道具项的 name/description 类型以及数组上限仍需满足。

背景引用是可选增强。未知背景 ID、空引用与匹配模式不一致、或精确引用缺少固定 description 时，编译结果改用 backgroundId=null/referenceMatch=none，只保留本轮 scene.name/description，并记录提示。原始模型响应保留，不模糊匹配其他背景、不修改资料库、不追加模型调用。已有有效 exact 引用仍补入原固定描述，nearby 仍不补入。
